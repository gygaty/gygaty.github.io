# Gabrielly Balão — Professional Portfolio

English-language portfolio for Gabrielly de Oliveira Balão, focused on CRM & Marketing Operations, B2B Growth Strategy and Customer Lifecycle.

## Preview

Open `index.html` directly, or serve this folder with a static server:

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Visit http://127.0.0.1:8000. No build, package installation or third-party services are required.

## GitHub Pages

Publish this folder at the root of a GitHub repository. In **Settings → Pages**, select **Deploy from a branch**, **main**, and **/(root)**. The `.nojekyll` file keeps the HTML/CSS/JavaScript site buildless. Relative asset links support both a personal domain and a repository subpath.

GitHub's official instructions: https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site
